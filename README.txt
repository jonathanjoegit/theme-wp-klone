KLONE — thème WordPress

INSTALLATION
Dans WordPress, ouvrir Apparence > Thèmes > Ajouter un thème > Téléverser un thème, choisir ce ZIP et activer le thème.

MODIFIER LE SITE
Dans le menu d’administration, ouvrir « Guide du site », puis cliquer sur « Modifier le site ».
La page « Modifier le site » regroupe les champs par sections. Choisir les images dans la médiathèque, coller le code Songkick ou newsletter dans le champ HTML, puis cliquer sur « Enregistrer les modifications ».
Les mêmes réglages restent disponibles dans Apparence > Personnaliser > Contenu KLONE pour l’aperçu en direct.
Les pages et articles se modifient avec l’éditeur WordPress.
Les comptes Administrateur et Éditeur peuvent modifier les réglages du thème.

SECTIONS MODIFIABLES
Identité et menu, album et pochette, bouton de pré-enregistrement (texte et URL), trois vidéos YouTube intégrées et leurs miniatures, dates et code Songkick, boutique externe, texte et code HTML newsletter, contacts et réseaux sociaux, pied de page.
Le lien Store du menu ouvre directement le Big Cartel.
Les URLs YouTube créent des lecteurs intégrés lorsqu’elles pointent vers une vidéo précise. Il est aussi possible de coller le code iframe YouTube.
Chaque réseau social peut être masqué ou affiché, et son URL est modifiable.
